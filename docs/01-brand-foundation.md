# 01 · Brand foundation (from Brandbook v1.0)

Source: `TAOMIQ_Brandbook_Modern_Premium.pdf` (12 pages, Tashkent 2026). This file is the website-facing summary: everything the site must obey.

## Essence

- **Name:** TAOMIQ = TAOM (food) + IQ (intelligence). Always written as one word.
- **Tagline:** «Умное питание. Каждый день.» / Premium Daily Nutrition
- **Mission:** make balanced eating tasty, aesthetic and convenient — no daily shopping, cooking or counting.
- **Four pillars:** Вкус (restaurant quality, variety) · Баланс (clear composition, kcal, БЖУ) · Забота (convenient service, reliable delivery) · Доверие (transparency, stable quality).
- **Handle:** @TAOM_IQ (Instagram). Domain: taomiq.uz.

## Logo rules

| Context | TAOM | IQ |
|---|---|---|
| Dark background | Ivory Cream `#F6F1E8` | Champagne Gold `#C7A86B` |
| Light background | Deep Forest `#183C34` | Champagne Gold `#C7A86B` |

- Monogram **TQ** in a thin gold circle: favicon, app icon, Instagram avatar, seals.
- Never stretch or change proportions. Use the simplified TQ at small sizes.
- Gold is an accent, never the colour of long text.
- A vector original (SVG) is still needed — the brandbook only contains a raster sketch. **Blocker for the site header/favicon/OG images.**

## Colour tokens

| Token | Hex | Role |
|---|---|---|
| `forest` | `#183C34` | Primary background, primary buttons on light |
| `ivory` | `#F6F1E8` | Light base background |
| `gold` | `#C7A86B` | Accent (IQ, key numbers, dividers, focus) |
| `sage` | `#A8B8A3` | Secondary surfaces, tags, borders |
| `graphite` | `#2D2D2A` | Body text |

Contrast notes for the web (WCAG):
- Ivory on Forest ≈ 11:1 and Graphite on Ivory ≈ 12:1 — both safe for body text.
- Gold on Forest ≈ 5:1 — fine for headings/labels. **Gold on Ivory ≈ 2.2:1 — fails for text**; on light backgrounds use gold only for decoration, never for readable text or button labels.

## Typography

- **Headings:** expressive modern serif. Brandbook illustration uses **Noto Serif Display**; it supports Cyrillic and Latin (needed for RU + UZ-Latin).
- **Body/UI:** **Manrope** or **Inter** (brandbook says "after checking against the previously approved font file" — to confirm). Both cover Cyrillic and Uzbek Latin (oʻ, gʻ).
- Minimal decoration. Data lines such as `TAOMIQ BALANCE / 1800` and `520 ккал · Б 38 · Ж 17 · У 54` are set in the sans with wide letter-spacing.

## Product architecture (programs)

| Program | Purpose | Site audience |
|---|---|---|
| **LIGHT** | Calorie control | Weight loss |
| **BALANCE** | Daily balance | Maintenance, busy professionals |
| **ACTIVE** | Active lifestyle | Fitness |
| **PROTEIN** | High-protein ration | Gym, cutting/recomposition |
| **GAIN** | Mass gain | Bodybuilding, bulking |
| **OFFICE** | Corporate meals | B2B |

- Same logo and packaging for all; only a coloured program tag differs.
- Calorie level is set separately inside each program (e.g. BALANCE / 1800).
- **Brandbook recommendation: launch with 3 programs**, expand after demand is proven.

## Voice

Calm confidence: modern, caring, competent. We explain the benefit; we do not promise miracles.

| Say | Avoid |
|---|---|
| «Питание под ваш ритм жизни» | «Похудей на 10 кг за неделю» |
| «Сбалансированно и вкусно» | «100% лечебное питание» |
| «Прозрачный состав каждого блюда» | «Уникальная волшебная диета» |
| «Больше времени для важного» | Aggressive discounts, loud banners |

Consequences for the site: no countdown timers, no flashing sale banners, no medical claims, no before/after weight promises. Discounts are shown as a quiet duration ladder.

## Imagery

Real photos of real dishes and real portions, calm compositions — **no stock photos**. Menu cards show the actual portion. This makes a food photo shoot a launch dependency.

## Labelling data the site must mirror

Every dish on the site carries the same data as the physical label: dish name, net weight, composition and allergens, kcal and БЖУ, shelf life/storage. Numbers are published only after the technological card is verified.

## Open brand inputs needed before design

1. Vector logo + TQ monogram (SVG).
2. Final body font decision (Manrope vs Inter).
3. Per-program tag colours (brandbook mentions coloured tags but does not define them).
4. Dish photography.
5. Final menu with weights and verified КБЖУ.
